# Release artifacts

Current version: **0.1.2-probe** (Android version code 3).

Download the personally signed ARM64 APK from [GitHub Releases](https://github.com/Srimi1/antigravity--mobile/releases/latest). Release assets include the APK, complete source archive and SHA-256 checksums. Local build copies are placed here and in `dist/`; APKs and ZIPs are distributed as release assets rather than stored in Git history.

Android 10+ and ARM64 are required. This is a validation prototype. Google/Claude subscription integration, live ChatGPT access and on-phone Android compilation have not passed the product gate.

The signing certificate is unchanged from 0.1.1, so this APK can update that installation. Keep the private signing key locally; it is excluded from Git and source archives.
