# Antigravity Mobile 0.1.2 — app icon and tested prototype

This release adds an original blue-and-violet launcher icon to the personal validation prototype, with adaptive masks, round launchers and an Android 13+ themed-icon silhouette. Repository cover artwork and the icon source are included with the code.

The app retains local workspace rollback, approved Android ARM64 command probes, cancellation, persisted check history, Compose sample generation, APK installer access and experimental ChatGPT sign-in testing. Version 0.1.1's checkpoint traversal, wrapper permission and generated-asset packaging fixes are included.

Validation: 11 JVM tests and 8 Android instrumentation tests pass on an Android 12 ARM64 emulator. Release lint, APK signing verification, installation and launcher icon inspection pass. The same personal signing certificate is used as before.

This is **not the completed three-provider agent app**. Google/Claude subscription access is blocked, live ChatGPT entitlement is unverified, the on-phone compiler toolchain is absent, and the physical OnePlus has not been tested. No paid API fallback is included.
