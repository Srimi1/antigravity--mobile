# Hello Web

Edit `index.html`, `styles.css` and `app.js` in Projects. Use the Website tab to preview saved changes or export a ZIP. The interactive button and local JSON request are real JavaScript.

Preview uses a copied folder, with external network requests blocked. Return to Projects and preview again after saving. Reload keeps the current copy. Website files are limited to 64 MB and 10,000 entries; hidden files, links and node_modules are excluded or refused. For a prebuilt frontend, choose its output entry such as `dist/index.html`. Node/package-manager builds, backend servers, external API requests and deployment are not provided by this preview.
