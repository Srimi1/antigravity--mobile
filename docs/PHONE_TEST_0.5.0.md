# Testing 0.5.0 (GitHub) on your OnePlus 7 Pro

Download `antigravity-mobile-0.5.0.apk` from https://github.com/Srimi1/antigravity--mobile/releases/latest and tap **Update**. Projects and accounts are kept.

## Sign in to GitHub (once)
1. Accounts → **GitHub** → **Create token on GitHub**. GitHub opens with the `repo` and `workflow` permissions already ticked. Pick an expiry and tap **Generate token**, then copy it.
2. Paste it into **GitHub token** → **Sign in**. Expected: "Signed in to GitHub as <you>".

## Work on a repository from the phone
1. Projects → All projects → **From GitHub**. Your repositories are listed. You can also search any public repository. Tap one to clone it.
2. Open the **Git** tab → **Branch** → type a name, e.g. `phone-edit` → **Create and switch**.
3. Edit files yourself in Files, or ask the Agent. Review agent edits in **Changes**.
4. Git tab → **Commit all** (or commit from Changes) → **Push**.
5. **Pull request** → enter a title → **Push and open PR** → **View pull request** opens it on GitHub.
6. For a project made on the phone: Git tab → **Publish to GitHub** creates a new repository (private by default) and pushes.

## ChatGPT models
Accounts → ChatGPT → **Models** now shows every model OpenAI returns to this app, with their real names. Models outside the recommended list are marked and may be refused. If a model you see in the ChatGPT app is missing, OpenAI is not offering it to third-party apps.
