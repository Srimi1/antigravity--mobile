# Branding assets

`app-icon.png` is the original transparent icon source. `repository-cover.png` is the matching repository artwork. Both were generated with the built-in image-generation tool, then copied into this repository. Android density variants were mechanically resized with macOS `sips`; the source transparency is preserved.

The adaptive foreground uses a separate dark background; Android applies the launcher mask. A vector silhouette supplies the Android 13+ themed icon. No Google or provider logo is used.

## Icon generation prompt

Use case: logo-brand. Asset: original Android adaptive launcher icon foreground for a personal development app named Antigravity Mobile. Create one premium, clean, sculptural symbol: two thick floating code chevrons forming a compact upward motion mark, with a small luminous suspended square between them, evoking code rising weightlessly. Crisp polished cobalt, ice blue and soft violet surfaces, restrained depth, very subtle glow, high contrast at tiny sizes. Transparent background. Square image, front-facing symmetric composition; entire symbol fits the center 56% of the canvas with generous transparent padding for Android adaptive icon masking. No letters, words, typography, frame, rounded background tile, watermark, Google logo or existing brand marks. One cohesive easily recognizable icon, no scattered decorative particles.

## Cover generation prompt

Use case: logo-brand. Create a premium landscape GitHub repository cover artwork, approximately 2:1 wide composition, for Antigravity Mobile. Use the supplied original icon as the exact identity reference: paired thick sculptural blue/violet code chevrons and luminous suspended central square. Preserve the identity of the mark. Place that symbol centrally, floating in a subtle dark navy space with restrained blue-violet light trails and an elegant grid fading into the distance, generous negative space, clean professional development-tool visual, crisp material details. No text, letters, typography, app screenshots, extra symbols, planets, brand logos or watermarks. This is artwork only, not a product UI or a claim about implemented features.
